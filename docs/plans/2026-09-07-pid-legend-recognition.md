### 3. SP02 族（六张）——符号已炸开（二期，已落地）

- 图层 `T-SYMBOLS` / `T_ZNACKY` / `T-MaR-ZNACKY`（捷克语 značky = 符号）/ `YIBIAO` / `DEVICE`；整张图只有 1~3 个 INSERT（`11111`、`RC`、徽标 `1`）。聚簇只在用了这些图层之一的图上跑（`shapes.layers_any`）。
- 圆符号按**圆内文字**分：仪表圈 r 1.6~4.2 且圈内是"字母行 + 数字行"（HS/0320A、FQRC/0301、LIA/0302A…，六张图 275 个圈 100% 读出位号）；`M` 小圆（r 1.0 / 1.18 / 1.75）= 电动执行器；`D` 小圆（r 0.93）= D 点（排净点）；r 5.19 / 6.23 空圆 = 泵（SP02-05 五台 ↔ P-0407~0411）。盘装仪表的方框在这一族是两条 LWPOLYLINE 画的，盘装判据已把折线边算进去（SP02-05 38 个盘装全认出）。
- 符号本体极小：球阀 1.3×0.8 mm、闸阀 2.3×4.5 mm、位号字高 1.96 mm；阀坐在管线上，用"端点相接"会把整条支管连成一块，所以 **> 2.5 mm 的轴向直线不参与连通**（`pipe_stub_mm`），阀的 X 形两条对角线按"相交"算相接。
- 位号形状 → 类别（`tag_classes`）：`BV9999*` 球阀、`GV9999*` 闸阀、`CV9999*` 止回阀、`PSV9999*` 安全阀、`XV-9999*` 电动阀、`CVV9999*` 呼吸阀、`FA9999*` 阻火器、`FI9999*` 流量指示、`FQ9999*` / `FM9999*` 流量计、`QK-9999*` 快速接头。10 mm 内、宽高都 ≥ 0.8 mm 的最近分量被认领，全图按距离贪心一对一。
- 形状字典（`shapes.dictionary`，按 id）：`f510fd60` / `38fb58d8` 流向 / 接图箭头（位号 `*DWG-*`）、`322720ec` / `62a8c552` 电动阀本体（位号取最近 XV 圈，SP02-05 27/27）、`2948f064` 带执行机构阀（有 FV 圈的取 FV 位号）。字典里 `"class": "ignore"` = 不是符号，不框也不报（盘装框、联锁菱形这类附属图形）。宽或高 < 0.3 mm 的未命名形状（共线的两道刻线）不框（`min_side_mm`）。
- 未命名形状的逐个截图（形状单独一格 + 12 mm 上下文 + 说明）由 `%TEMP%\dxf-legend\shape_sheets.py` 从 `dxf_legend --json` 与 `--write` 的产物生成，供人命名后补进字典。
- 六张图合计：位号认领 282 个分量；剩 55 条位号无主，其中 16 条是 `XV-0407A～0409A` 这类**范围标注**（不是位号）、18 条 `LA-` 中 12 条是范围标注 + 每张 2 只鹤管块上方没有位号；真正漏的是阻火器 FA（7，符号全由 2.7 / 3.2 mm 轴向线画成，被管段规则滤掉）、SP02-05 的 FI（5，同因）、闸阀 GV（4）、QK（3）。报告里 `ORPHAN` 行原样列出。
- 已知局限：同一支管上挨着的阀（PSV + GV）仍是一个分量，框成一个"阀组"，标签把两个位号都列出来（`安全阀 PSV0407A + GV0407B + GV0407A`）；未命名形状（`图形 <id>`）要人看一眼再进字典。

### 4. 位号 / 文字的形状规则

规则文件用的形状语法：`9` = 一位数字，`?` = 一个大写字母，`*` = 其后任意，其它字符字面匹配。

| 类别 | 形状 | 例 |
|---|---|---|
| 阀位号 | `BUV-9999` | BUV-3101 |
| 仪表圈 | 圈内两行合成：字母行 + 数字行 → `XV-3201`、`HS-0320A` | XV, 3201 |
| 设备号 | `T?-9999`（圈内） | TG-0101, TD-0208 |
| 图幅引用 | `DWG-*` | DWG-0100FF02-04 |
| 管号（未用于关联） | `^\d+-[A-Z]{1,3}(-\d{5}-[A-Z]\d)?$` | 200-FW-32002-A2 |
| 尺寸（要排掉） | 含 `"` / `NPT` / 以 `DN` 开头 | 1/2"NPT |

### 5. 识别方法按可靠度排序

1. **块名查表**（块名 → 类别）——全套唯一签名，最可靠。
2. **圆 + 圈内文字**：半径粗筛，圈内文字定类（字母 + 数字 = 仪表圈；S/K/M/D 单字母各一类；空 + 大圆 = 泵 / 储罐）。
3. **图层 = 大类**：`VALVE_` / `EVALVE_` / `EQUIP_` / `PIPE-`，后缀是专业——新块名的兜底。
4. **邻近文字绑定**：类别专属形状 + 半径 + 全图最近优先一对一（阀间距 9 mm 时上下两个 BUV 都在半径内，按距离配最近的：实测 2.7~8.6 mm）。炸开族反过来用：位号形状决定旁边那团笔画是什么。
5. **几何签名聚簇** + 形状字典——炸开族的兜底，没进字典的按 id 配色框出并报告。
