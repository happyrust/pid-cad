### 4. 位号 / 文字的形状规则

规则文件用的形状语法：`9` = 一位数字，`?` = 一个大写字母，`*` = 其后任意，其它字符字面匹配。

| 类别 | 形状 | 例 |
|---|---|---|
| 阀位号 | `BUV-9999` | BUV-3101 |
| 仪表圈 | 圈内两行合成：字母行 + 数字行 → `XV-3201`、`HS-0320A` | XV, 3201 |
| 设备号 | `T?-9999`（圈内） | TG-0101, TD-0208 |
| 图幅引用 | `DWG-*` | DWG-0100FF02-04 |
| 管号（未用于关联） | `^\d+-[A-Z]{1,3}(-\d{5}-[A-Z]\d)?$` | 200-FW-32002-A2 |
| 尺寸（要排掉） | 含 `"` / `NPT` / 以 `DN` 开头 | 1/2"NPT |

### 5. 识别方法按可靠度排序

1. **块名查表**（块名 → 类别）——全套唯一签名，最可靠。
2. **圆 + 圈内文字**：半径粗筛，圈内文字定类（字母 + 数字 = 仪表圈；S/K/M/D 单字母各一类；空 + 大圆 = 泵 / 储罐）。
3. **图层 = 大类**：`VALVE_` / `EVALVE_` / `EQUIP_` / `PIPE-`，后缀是专业——新块名的兜底。
4. **邻近文字绑定**：类别专属形状 + 半径 + 一对一（阀间距 9 mm 时上下两个 BUV 都在半径内：实测 2.7~8.6 mm）。配对不是逐个取最近——一排等距的阀配一排等距的位号时最近优先会整排错位（D10），取全图**最大匹配里总距离最短**的那组。炸开族反过来用：位号形状决定旁边那团笔画是什么。第一遍没配上的位号还有第二遍（D11）：把管段规则滤掉、但被别的笔画在两处以上接住的轴向线请回来再连一次，只给这些位号认领。
5. **几何签名聚簇** + 形状字典——炸开族的兜底，没进字典的按 id 配色框出并报告。
