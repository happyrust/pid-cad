### 2. 非块符号（散实体）——块名查表拓不到，要按几何 + 文字识

FF02 族通用（FF02-04 的数）：

| 模块 | 画法 | 数 | 识别特征 |
|---|---|---:|---|
| 储罐（平面） | 圆 + 十字线，内写 TG-010x / TD-020x + 容积 | 6 | 层 `0` CIRCLE，r = 23 mm（10000 m³）或 13.4 mm（5000 / 3000 m³）；十字线是 `0GL-PM` 层 LINE；上标"3"是 h=132 的小字 |
| 仪表圈（现场） | 圆 r = 3.85 / 3.7 mm，内 XV / HS + 4 位号 | 18 | CIRCLE 内含 2 条 TEXT（功能字母 + 回路号） |
| 仪表圈（盘装 / DCS） | 圆 r = 3.7 mm 套在方框里，HS | 6 | 圆外 ≥3 条长约 2r 的 LINE 围成方框 |
| S 小圆 | r = 2.1 mm 圆内 S（泡沫图上是 K），在每只罐顶 / 底 | 12 | 150-FW 喷淋支管接入点（S / K 含义待图例） |
| 管线 | LWPOLYLINE 两点一段，常宽 0.35 mm | 135 | 层 `PIPE-消防`；管号沿线标 `\d+-FW(-\d{5}-A2)?` |
| 流向箭头 | SOLID | 14 | 层 `PIPE-消防` |
| 仪表引线 | 层 `0` LINE 7.4 / 2.4 mm | 36 | 从仪表圈到阀 |

层 `0` 的圆**全部**内含文字——所以「圆 + 圆心附近文字」是仪表圈 / 储罐 / S 点三分的稳定判据，按半径分档即可。

### 3. SP02 族（六张）——符号已炸开（二期）

- 图层 `T-SYMBOLS` / `T_ZNACKY` / `T-MaR-ZNACKY`（捷克语 značky = 符号）/ `YIBIAO` / `DEVICE`；整张图只有 1~3 个 INSERT（`11111`、`RC`、徽标 `1`）。
- 仪表圈是 r = 2.94 / 3.0 / 2.25 mm 的散圆，**落在 TWT 族的半径档之外**（用 TWT 规则跑会把 HS 圈当成 S 点）——规则必须按图族选，这是 D3 把规则放文件里的理由。
- 需要**几何签名聚簇**：去掉图框/标注层，笔画 >14 mm（管线）和 r>8 mm 的圆（储罐）不参与，剩下按"端点相接"连通分量，对包围盒中心归一，取 8 种旋转/镜像中字典序最小的作签名，同签名归一类。全套 173 类（n≥2 的 85 类），原型在 `%TEMP%\dxf-legend\dxf_cluster.py`。
- 已知局限：笔画不相接的符号会被拆开（仪表圈与引线），靠在一起的阀组会被合成一块。

### 4. 位号 / 文字的形状规则

规则文件用的形状语法：`9` = 一位数字，`?` = 一个大写字母，`*` = 其后任意，其它字符字面匹配。

| 类别 | 形状 | 例 |
|---|---|---|
| 阀位号 | `BUV-9999` | BUV-3101 |
| 仪表圈 | 圈内两行合成：字母行 + 数字行 → `XV-3201`、`HS-0320A` | XV, 3201 |
| 设备号 | `T?-9999`（圈内） | TG-0101, TD-0208 |
| 图幅引用 | `DWG-*` | DWG-0100FF02-04 |
| 管号（未用于关联） | `^\d+-[A-Z]{1,3}(-\d{5}-[A-Z]\d)?$` | 200-FW-32002-A2 |
| 尺寸（要排掉） | 含 `"` / `NPT` / 以 `DN` 开头 | 1/2"NPT |

### 5. 识别方法按可靠度排序

1. **块名查表**（块名 → 类别）——全套唯一签名，最可靠。
2. **图层 = 大类**：`VALVE_` / `EVALVE_` / `EQUIP_` / `PIPE-`，后缀是专业——新块名的兜底。
3. **邻近文字绑定**：类别专属形状 + 15 mm 半径 + 全图最近优先一对一（阀间距 9 mm 时上下两个 BUV 都在半径内，按距离配最近的：实测 2.7~8.6 mm）。
4. **几何签名聚簇**——SP02 族必需（二期）。

### 一期验收（`tests/pid_legend.rs`）

- FF02-06：118 个符号；16 蝶阀 ↔ 16 个不重复 BUV-3201~3216；8 电动阀 ↔ XV-3201~3208；8 储罐全带号；16 现场 + 8 盘装仪表圈全带号；未知块 0；无落单 BUV。
- FF02-05：145 个符号；24 蝶阀 ↔ 24 BUV；11 电动阀 ↔ 11 XV；6 储罐；22 + 11 仪表圈。
